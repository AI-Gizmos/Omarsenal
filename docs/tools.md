# Tools

Every package Omarsenal can install, by category. Install a category with `./install.sh --<category>`.

| Category | Package | Purpose |
| --- | --- | --- |
| foundation | docker, docker-compose, docker-buildx | Containers for lab targets and isolated tooling |
| foundation | tmux | Terminal multiplexer for long-running sessions |
| foundation | git, base-devel | Source control and AUR build tools |
| foundation | python | Runs the scope guard |
| foundation | util-linux | Provides `script` for session logging |
| foundation | libnotify | Desktop notifications on mode changes |
| recon | nmap | Port scanning and service detection |
| recon | masscan | Fast large-range port scanning |
| recon | whois | Domain and IP registration lookups |
| recon | bind | `dig` and `host` for DNS queries |
| recon | dnsrecon | DNS enumeration and zone checks |
| recon | amass | Subdomain discovery and attack surface mapping |
| recon | theharvester | Emails, names and hosts from public sources |
| web | burpsuite | Intercepting proxy for web testing |
| web | ffuf | Fast web fuzzer for content and parameters |
| web | gobuster | Directory, DNS and vhost brute forcing |
| web | sqlmap | SQL injection detection and exploitation |
| web | nikto | Web server misconfiguration scanner |
| web, passwords | seclists | Wordlists for fuzzing and cracking |
| exploitation | metasploit | Exploitation framework |
| exploitation | exploitdb | Local exploit database with `searchsploit` |
| passwords | hashcat | GPU password cracking |
| passwords | john | CPU password cracking and hash format tools |
| passwords | hydra | Online login brute forcing |
| network | wireshark-qt | Packet capture and analysis GUI |
| network | tcpdump | Command-line packet capture |
| network | responder | LLMNR, NBT-NS and mDNS poisoning |
| network | python-impacket | Windows and AD protocol tooling |
| ad | bloodhound | Active Directory attack path mapping |
| ad | netexec | Network service and AD enumeration and execution |
| blue | suricata | Network IDS for blue and purple modes |
| blue | zeek | Network traffic analysis and logging |
| workflow | obsidian | Engagement notes and writeups |
